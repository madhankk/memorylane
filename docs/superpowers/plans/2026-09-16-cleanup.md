# Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add reversible cleanup marks and a review flow, then extend it with safe source-aware deletion and discovery tools.

**Architecture:** Store explicit marks separately from media metadata and exclude marked rows through the central media query. Rendered-batch selection operates in the client; Cleanup queries the marked rows directly. A later trash service owns filesystem mutations, while tag and suggestion analyzers own derived metadata.

**Tech Stack:** Fastify, better-sqlite3, React 18, TypeScript, Vitest, existing analysis worker and CLIP sidecar.

**Spec:** `docs/superpowers/specs/2026-09-16-cleanup-design.md`

## Global Constraints

- Preserve user edits and the existing read-only Apple Photos package invariant.
- Never let AI mark or delete a file.
- Selection inversion affects only rendered thumbnails; collapsed stack selection affects only its cover.
- Keep the existing root safety checks for every filesystem operation.
- Existing indexed media must work after migration without a full source rescan.
